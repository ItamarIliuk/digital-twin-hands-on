# Digital Twin Hands-on

Public page: https://itamariliuk.github.io/digital-twin-hands-on/

From a cell in Isaac Sim to the UR controller: a UR10 palletizing cell that learned the task in NVIDIA Isaac Lab and
had its commands executed by the Universal Robots controller software (URSim). This repository also holds the open
materials of the *Digital Twin Hands-on* workshop (IA Summit Passo Fundo, Brazil, November 27, 2026):

- `guia.html` — official Isaac Sim and Isaac Lab examples to practice at home or on NVIDIA Brev (PT/EN)
- `exercicios.html` — four exercises with the project data, including a Clopper-Pearson reliability calculator (PT/EN)

Developed at LABRIOT (Laboratório de Robótica e IoT), UTFPR Ponta Grossa, Brazil, as part of Dr. Itamar Iliuk's
activities as an NVIDIA Omniverse Ambassador. LABRIOT is a member of the NVIDIA Inception program.

**Simulation research only.** Nothing here has run on a physical robot. This repository holds only the static web
page (`*.html` and `assets/`). Cell 3D assets: NVIDIA Isaac Sim asset libraries. Product names are trademarks of their
owners; this project is not endorsed by NVIDIA or Universal Robots.
